Authentication

  1. Create a free account. Sign up with your work e-mail; every account starts with sandbox credits.
  2. Get access. Request sandbox or production access for this API in the API catalog. Production access is approved by an administrator, who sets your quota.
  3. Create an API key under API keys for that environment. It is shown once; keep it on your server.
  4. Exchange the key for a token. POST {{ tokenUrl }} with header X-API-Key: <key>. The answer is {{ '{' }} "access_token", "token_type": "Bearer", "expires_in": 900 {{ '}' }}. Reuse the token until it expires instead of exchanging on every call.
  5. Call the API with Authorization: Bearer <access_token>.
Sandbox keys (gativra_test_…) give sandbox tokens, which only the sandbox endpoint accepts. Production keys (gativra_live_…) give production tokens.
